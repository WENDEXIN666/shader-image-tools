📖 How to Use

🚀 Quick Start

  1. Upload — click the blue Upload Image button and pick a photo. On mobile you can take a photo or choose one from your gallery.
  2. Filter — tap any filter button to apply it instantly. All effects render on the GPU in real time.
  3. Adjust & Save — fine-tune the Blur / Sharpen sliders, then click Save Image to download the result as PNG.

🔬 Filter Algorithms (GLSL Fragment Shaders)

Grayscale Weighted luma conversion (ITU-R BT.601) — weights mimic human eye sensitivity (green > red > blue). gray = 0.299·R + 0.587·G + 0.114·B
Sharpen Laplacian edge enhancement — samples the 4-neighbourhood and amplifies the difference from the center. out = center − (right + left + top + bottom − 4·center) × amount
Blur 7×7 kernel convolution — each pixel blends with its neighbours, weight decreasing with distance. out = Σ weight(x,y) · tex(uv + (x,y)·radius) / Σ weight
Edge Sobel operator — computes horizontal and vertical gradients, then keeps strong responses via smoothstep. edge = √(Gx² + Gy²), Gx = |right − left|, Gy = |top − bottom|
Flip H / V Mirrors the UV texture coordinates. H: uv.x → 1 − uv.x  |  V: uv.y → 1 − uv.y
Twist Spiral warp — rotates each pixel around the image center by an angle proportional to its distance from the center. angle = dist(uv, center) × 8.0
Reset Displays the original unfiltered texture.

🎛️ Parameters

Blur slider Convolution sampling radius. 0 = original image (no blur).
Sharpen slider Laplacian amplification factor. 0 = original image.

💡 Tips

• Every filter runs on the GPU (WebGL fragment shaders) — no server upload, all processing stays in your browser.

• Reset restores the original image without re-uploading.

• Save Image downloads the current canvas as a PNG file.
